# 🚗 Vehicle Service Center Management System

A desktop-based Vehicle Service Center Management System developed using **Java Swing**, **JDBC**, and **MySQL**. This application simplifies the vehicle servicing process by allowing customers to register, book services, track service status, make payments, and view service history.

## ✨ Features

- 👤 Customer Registration & Login
- 📋 Service Booking
- 🔧 Service Status Tracking
- 💳 Payment Management
- 📜 Service History
- 👨‍💼 Admin Dashboard
- 🗄️ MySQL Database Integration
- 🖥️ User-Friendly Java Swing Interface

## 🛠️ Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Apache NetBeans IDE

## ⚙️ Prerequisites

- JDK 17 or later
- Apache NetBeans
- MySQL Server
- MySQL Connector/J (JDBC Driver)

## 🚀 How to Run

1. Clone this repository.
2. Import the project into NetBeans.
3. Create the MySQL database and import the SQL file.
4. Update the database username and password in the connection class.
5. Build and run the project.
